## Подготовка

Для поднятия проекта нужен docker, для удобного управления еще и make.

```
# Установка докер
curl -fsSL https://get.docker.com -o get-docker.sh
sh get-docker.sh

# Установка make
sudo apt update && sudo apt install make -y 
```

Далее все команды буду использовать через make, но если вы его не усталовили, можете посмотреть их в Makefile и повторить самостоятельно.


## Поднимаем проект

Создаем файл с переменными .env

`make envs`

Заполняем своими данными файл .env . Далее поднимаем проект

`make up`

Проект поднят на `127.0.0.1:8000`
